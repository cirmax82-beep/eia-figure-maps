# 사업지 도면 만들기

사업지구 경계를 넣으면 **위성사진 현황도·생태축 현황도·생태·자연도·한국 식생기후대 분포도·한국 식물상 지역** 도면을 보고서에 바로 붙일 수 있는 PNG·PDF·SVG로 만듭니다.

- 주소: https://maps.biogrideia.com/
- 호스팅케이알 DNS의 CNAME 레코드(`maps` → `cirmax82-beep.github.io`)로 연결합니다. 처음 쓰던 map.biogrideia.com은 GitHub 인증서 발급이 실패 상태로 남아 maps로 옮겼습니다(새 하위 도메인은 DNS를 먼저 넣고 퍼진 뒤 GitHub에 연결).

## 쓰는 법

1. **경계 넣기**: SHP(zip 또는 .shp+.prj)·GeoJSON·KML·DXF 파일, 좌표 붙여넣기(경위도·TM, 성과표 순서 자동 판별), 지도에 그리기. 파일은 브라우저 안에서만 읽고 어디에도 보내지 않습니다.
2. **도면 고르기**
   - 위성사진 현황도: 위성영상 + 사업지구 + 주변 범위(기본 1·2 km)
   - 생태축 현황도: 위성영상 + 산림생태계(활엽·침엽·혼효림) + 수생태계(토지피복 하천·호소·습지, 실폭하천·호수/저수지, 하천구역, 소하천구역, 바다) + 산·저수지·하천 이름 + 하천 흐름 방향. 미리보기 위에 산림축(녹색)·수계축(청색) 화살표를 직접 그릴 수 있습니다.
   - 생태·자연도: 브이월드 백지도(선을 진하게 처리) + 1·2등급·별도관리지역(3등급은 흰색) + 사업지구. 색은 에코뱅크 기준(1등급 #1ea725, 2등급 #cfe3c9, 3등급 #FFFFFF, 별도관리지역 #F37E16)으로, 흑백 바탕이면 불투명하게 칠하고 바탕 선·지명을 위에 다시 얹으며 위성·컬러 바탕이면 바탕이 비치게(70%) 칠합니다. 선택하면 도면에 보이는 범위 안 1등급 권역까지 가장 가까운 거리를 치수선으로 표시(1 m 단위, 1 m 미만은 cm). ‘등급별 면적표 받기(엑셀)’로 사업지구 안 1·2·3등급·별도관리지역 면적을 받음(3등급은 나머지, EPSG:5186 평면 넓이). 공공데이터포털 키를 저장하면 국립생태원 최신 DB(API)로도 계산
   - 한국 식생기후대 분포도·한국 식물상 지역: 남한 전국 지도(위성 바탕) + 사업지 점·이름 + 사업지 확대 그림(선택)
   - 문헌조사시 법정보호종 출현위치도(탭 ‘법정보호종(문헌조사)’): 문헌조사 위치도(같은 9격자·문헌 목록·직접 찍은 위치·문헌자료 표)에 법정보호종을 위치별 글자 상자로 더합니다. BioGrid EIA 포털에서 주소로 문헌을 받을 때 함께 받은 `protected_species.geojson`(또는 `spatial_layers.zip`)을 넣으면, 종마다 붙은 문헌 번호로 위치를 정합니다 — 전국자연환경조사는 그 도엽 칸, 조류센서스·내륙습지·생물측정망·하천조사 유역처럼 위치가 있는 문헌은 그 구역, 위치가 없는 종은 문헌자료 표 아래 「주) 정확한 출현위치가 기재되지 않은 법정보호종」. 문헌 목록이 비어 있으면 이 파일의 문헌 목록을 씁니다. 상자 색은 문헌 종류에 맞춥니다. 위치마다 「종(문헌 번호)」을 고치고 지울 수 있고, 칸·문헌 위치·주석·지도에 직접 찍은 지점으로 새 위치를 더합니다. 평가서처럼 직접 넣은 문헌 위치나 「지도에 찍기 — 문헌N」으로 찍은 지점에 종 이름만 적으면 그 문헌 번호가 붙어, 한 문헌의 종을 여러 지점에 나눠 찍을 수 있습니다. 법정보호종이 없는 문헌은 이 도면의 기호·문헌자료 표에서 빠지고(번호는 문헌조사 위치도 그대로라 빈 번호가 생김), 9격자는 늘 바탕으로 그립니다.
   - 보호구역 위치도: 문헌조사 위치도와 같은 9격자 범위에 보호구역 종합포털(protect.biogrideia.com)의 보호구역을 종류별 색으로 그립니다. 9격자에 걸치는 구역만 원본 해상도 경계를 받아 격자 안쪽만 칠하고, 이름·범례(그려진 종류만)·도엽 이름을 붙입니다. 기본은 동식물상 관련 종류(야생생물(특별)보호구역, 습지·연안습지보호지역, 생태·경관보전지역, 특정도서, 국립·도립·군립공원, 산림유전자원보호림, 백두대간보호지역, 천연기념물, 해양보호구역)이고 30종 모두 켜고 끌 수 있습니다. 선택하면 사업지구에서 각 구역의 가장 가까운 지점까지 이격거리를 치수선으로 그리고, ‘9격자 안 보호구역 목록 받기(엑셀)’로 종류·이름·고시·면적·관계(겹침/이격)·이격거리(EPSG:5186 평면)·방향(8방위)을 받습니다.
   - 현지조사 위치도: 위성영상 + 사업지구 + 조사범위 + 조사경로(점선) + 조사지점. 조사범위는 사업지구 경계에서 잰 거리(m)와 조사 항목 이름을 직접 정하고 켜고 끄며, 같은 거리는 선 하나로 그립니다. 처음 값은 <표 6.1.1-3 조사항목별 현지조사 범위>를 따릅니다(면사업: 식물상·식생, 양서·파충류·육상곤충 100 m, 포유류·조류 300 m / 선형사업: 150 m·500 m, 보호지역이 가까우면 넓히는 500 m 줄은 꺼 둠). 조사원들이 등산·경로 앱에서 받은 GPX·KML·KMZ·GeoJSON을 한꺼번에 넣으면, 튀는 점·차량 이동(시각이 있으면 앞뒤 15초 평균 시속 15 km 넘는 구간)·사업지구에서 먼 길(기본 2 km 밖, 앱을 켠 채 돌아간 길 등)을 빼고, GPS 잔떨림을 펴고(다듬기 그대로·약하게·보통·강하게), 다른 경로나 되돌아온 길이 겹친 곳(기본 15 m 안)은 하나로 합칩니다. 잘못된 길은 미리보기에서 지우개로 문질러 지우고, 빠진 길은 직접 그립니다(꺾인 곳은 둥글게, 끝이 기존 길 가까이면 붙임). 고친 것은 경로를 더 넣거나 설정을 바꿔도 그대로 남습니다. 식생(St.)·육수(W.)·기타 조사지점은 미리보기를 누를 때마다 차례로 찍히고(지점만 든 KML도 조사지점으로), 이름을 고칠 수 있습니다. 분류군별 색으로 나눌 수 있고(파일 이름으로 짐작), ‘조사지점 좌표(엑셀)’로 경위도(도분초·십진)·EPSG:5186 좌표를, ‘정리한 경로(KML)’로 합치고 고친 경로를 받습니다. ‘저장(파일)’은 경로·조사범위·고친 것·조사지점과 경계를 .json으로 저장합니다.
   - 현지조사시 법정보호종 출현위치도·현지조사시 생태계교란생물 출현위치도(탭 ‘법정보호종(현지조사)’·‘생태계교란생물(현지조사)’, 같은 방식): 위성영상 + 사업지구 + 현지조사 범위(분류군과 상관없이 가장 큰 거리 하나 — 비우면 현지조사 위치도에서 켠 범위 중 가장 큰 것) + 출현 기록(점·선·면 — 교란식물 대군락 등, 종마다 다른 색·기호, 범례는 분류군 차례로 「수달(멸종위기 Ⅰ급, 천연기념물)」·「가시박」). 출현 기록은 종명을 적고 미리보기에 점·선·구역(면)을 그리거나(점은 누를 때마다, 선·구역은 두 번 눌러 하나씩 — 그만두기까지 계속), GPX·KML·KMZ·GeoJSON·SHP(zip)의 점·선·면(이름·설명·속성에서 목록의 종 이름을 찾음 — 「수달 배설물」 → 수달, 비고 배설물. 목록에 없는 이름은 빼고 알려 줌)·엑셀·CSV(점, 종명과 위도·경도 또는 X·Y(EPSG:5186, Y가 100만 넘으면 5179) 열, CSV는 UTF-8·CP949)로 넣습니다. 목록에는 면적(㎡)·길이(m)(EPSG:5186 평면)가 나옵니다. 범위를 조금 벗어난 지점도 넣을 수 있게 ‘범위 밖 지점’을 모두·500·200·100 m까지·범위 안만 중에서 고르고(목록에 범위 안/밖 거리 표시), 자동 축척은 그린 지점까지 맞춥니다. 지점마다 종명을 붙이고(끌 수 있음), 조사경로 겹치기는 선택. ‘출현 기록 받기(엑셀)’는 분류군·종명·법적지위(교란생물은 학명)·형태·면적·길이·비고·위치(선은 길이 가운데, 면은 무게중심, 도분초·십진·EPSG:5186)·사업지구와 거리·범위 안/밖과 종별 요약(점 수·선 길이 합·면적 합), ‘저장(파일)’은 .json.
   - 문헌조사 위치도: 사업지구 가운데가 든 1:25,000 도엽 칸(도엽을 3×3으로 나눈 E1~E9)과 둘레 8칸(9격자)이 틀에 꽉 차게 그리고, 칸 이름·도엽 이름(번호), 9격자 도엽의 전국자연환경조사 문헌을 자동으로 넣습니다. BioGrid EIA 포털에서 필요한 문헌을 골라 받은 문헌 엑셀(`literature_by_taxon.xlsx`의 ‘문헌목록’)을 넣으면 문헌 목록과 번호가 그대로 바뀌고, 문헌 이름으로 겨울철 조류 동시 센서스 조사지역·내륙습지·생물측정망 지점·전국자연환경조사 하천조사 유역을 찾아 바로 그립니다(포털의 `spatial_layers.zip`도 넣을 수 있음). 위치 자료가 없는 기타 평가서·연구자료는 미리보기 위에 지점·선·구역으로 직접 찍고 이름을 적습니다. 문헌 엑셀에 위치 정보가 없는 문헌(평가서 등)이 들어 있으면 목록의 ‘위치 찍기’로 도면 위에 점을 찍어 위치를 정합니다. 문헌자료 표는 ‘도면 아래’, ‘둘째 쪽(도면은 크게)’, ‘넣지 않음’ 중에서 고릅니다. 표는 10건까지 한 열, 넘으면 두 열로 반씩(17건이면 9·8건) 나누고, 넘치면 글자를 줄입니다. 둘째 쪽이면 미리보기에서 1쪽·2쪽을 바꿔 보고, PDF는 두 쪽 한 파일, PNG·SVG는 도면과 문헌자료 두 파일로 받습니다. 목록에서 체크를 풀면 빠지며 번호가 다시 매겨지고, ‘문헌 목록 받기(엑셀)’로 같은 번호의 목록을 따로 받을 수 있습니다. 생태·자연도 1·2등급을 겹칠 수 있습니다. ‘목록 저장(파일)’은 직접 찍은 위치·고친 문헌 이름·색·뺀 문헌·넣은 포털 자료와 경계를 .json 파일로 저장하고, ‘불러오기’로 되살립니다(경계를 넣기 전에 불러오면 파일의 경계도 넣음).
3. **바탕지도**: 위성영상(Esri·브이월드), 브이월드 기본지도·백지도(흑백으로 진하게), 지형 음영(Esri), 흰 바탕 중에서 고르고, 밝기·흑백·지명 겹치기(브이월드)를 정합니다. 브이월드 바탕은 인증키가 있어야 합니다.
4. **경계 이름**: 사업지구·계획지구·사업노선·사업하천·계획하천·계획노선·조사대상지 등으로 고치면 범례와 도면 글자에 씁니다(선은 처음부터 사업노선).
5. **용지·축척**: A4·A3, 가로·세로, 축척 자동(범위에 맞춤) 또는 1:1,000~1:100,000. 미리보기를 끌면 가운데를 옮기고, 마우스 휠로 축척을 한 단계씩 바꿉니다.
6. **도면 요소**: 제목, 방위표, 축척 막대, 범례, 좌표 격자(경위도·TM 중부원점), 출처를 켜고 끕니다. 이름표는 숨기거나 고칠 수 있습니다. ‘글자·기호 크기’(작게~가장 크게)는 글자·지점 기호·제목을 같이 키우고(여백·지도 틀은 그대로), ‘범례 크기’·‘축척 막대 크기’·‘방위표 크기’는 저마다 따로 정합니다(도면마다 따로). 방위표·축척 막대·범례는 크기와 상관없이 지도 틀에서 같은 거리에 놓입니다. 축척 막대 숫자가 겹치면 막대를 더 길게(틀 폭의 42%까지) 잡고, 그래도 겹치면 한 칸 건너 또는 양 끝에만 숫자를 적습니다. 범례·목록·주석·엑셀의 분류군 차례는 모든 도면에서 식물 → 포유류 → 양서·파충류 → 조류 → 육상곤충류 → 저서성 대형무척추동물 → 어류입니다(문헌조사 종 상자는 법정보호종 목록의 분류군으로 늘어놓음).
7. **받기**: PNG(해상도 정보 포함 — 문서에 넣으면 용지 크기로 들어감), PDF, SVG(바탕 영상만 그림, 나머지는 벡터). 200·300·400 dpi.

토지피복 면은 10 m 화소를 살짝 흐리게 한 뒤 등치선으로 바꾼 것이라 폭 10 m보다 좁은 개천은 빠지므로, 실폭하천·호수/저수지(지정 안 된 하천·수로·작은 저수지 포함)와 하천구역·소하천구역 면을 함께 칠합니다. 두 자료에도 빠진 물길(지정 구간 밖 상류 등)은 ‘하천 선(빈 곳 잇기)’이 OSM 하천 선으로 이어 칠합니다. 수계는 출처가 겹치므로 불투명하게 칠합니다. 접경지역 등 토지피복 ‘분류 없음’ 지역은 산림·수계가 빠지며, 이때 미리보기에 알림이 뜹니다.

## 브이월드 인증키(생태·자연도 백지도)

`인증키 저장.bat`을 더블클릭해 maps.biogrideia.com으로 발급한 브이월드 인증키를 붙여 넣으면, 이 컴퓨터(`work/vworld_key.txt`, `js/config.js`, 모두 저장소 제외)와 GitHub 저장소 비밀값 `VWORLD_KEY`에 넣고 다시 배포합니다. 배포는 `.github/workflows/pages.yml`(GitHub Actions)이 합니다.

## 생태·자연도·식생기후대·식물상 지역 갱신

- 생태·자연도: 새 정기고시 GDB를 받아 `python tools/build_ecnat.py "<GDB 경로>" data/ecnat` (약 20분)
- 식생기후대: `python tools/build_vegclim.py "../보호구역 종합포털/work/raw/admin-sigg.geojson" data/vegclim` (CHELSA 한반도 범위만 원격으로 읽음)
- 식물상 지역: Dryad에서 `floristic_zones_and_ecoregions.zip`을 받아 `python tools/build_flora.py <zip> data/flora`

## 문헌조사 위치도 자료 갱신

BioGrid EIA 작업 폴더(`웹서비스 개발`)의 기준 도엽이나 전국자연환경조사 원자료가 바뀌면 `python tools/build_lit.py "<웹서비스 개발 폴더>" data/lit`로 다시 만듭니다.

## 하천구역·소하천구역 갱신

1. 하천구역: 국내 컴퓨터에서 `VWORLD_KEY_FILE=인증키파일 python tools/fetch_rivers.py work/raw/vw_strm.geojson` (브이월드는 해외 IP를 막음, 키는 저장소에 넣지 않음)
2. 소하천구역: 브이월드 데이터마켓 ‘(연속주제)_소하천/소하천구역’(dsId=30369)에서 로그인 후 시도별 `LSMD_CONT_UJ301_<시도>.zip`(EPSG:5186판, `_5174_` 아닌 것)을 받아 `work/raw/small`에 둠
3. `python tools/build_water.py work/raw/vw_strm.geojson work/raw/small data/water`
4. 실폭하천·호수/저수지: 브이월드 데이터마켓에서 로그인 후 ‘실폭하천’(`N3A_E0032111.zip`)·‘호수/저수지’(`N3A_E0052114.zip`)를 받아 `work/raw/ngii`에 두고 `python tools/build_topo.py work/raw/ngii data/topo` (약 3분)

## 이름·하천 자료 갱신

```bash
curl -L -o work/raw/south-korea.osm.pbf https://download.geofabrik.de/asia/south-korea-latest.osm.pbf
python tools/build_osm.py work/raw/south-korea.osm.pbf data/osm
```

필요한 파이썬 패키지: osmium(pyosmium), shapely, pyproj. 0.1도 조각(약 1,300개, 24 MB)과 `data/osm/index.json`을 다시 만듭니다.

## 파일

- `index.html`, `css/style.css`
- `js/input.js`: 경계 입력(보호구역 종합포털 사업지 분석 입력 코드를 옮김)
- `js/render.js`: 도면 그리기 — 용지 mm 좌표 펜(캔버스·SVG), 위성 타일, 토지피복 면, 이름표, 도면 요소
- `js/app.js`: 화면, 미리보기, 축 화살표, 받기
- `js/field.js`: 현지조사 위치도 — 경로 파일 읽기, 튀는 점·차량 이동·먼 길 빼기, 다듬기, 겹친 길 합치기, 지우개·그린 길 적용
- `tools/build_osm.py`: OSM 이름·하천 조각 만들기
- `tools/fetch_rivers.py`, `tools/build_water.py`: 하천구역·소하천구역 조각 만들기
- `tools/build_topo.py`: 실폭하천·호수/저수지 조각 만들기
- `tools/build_lit.py`: 문헌조사 위치도의 도엽 격자·전국자연환경조사 문헌 목록 만들기
- `tools/build_legal.py`: 법정보호종 목록(현지조사시 법정보호종 출현위치도) 만들기
- `tools/build_invasive.py`: 생태계교란 생물 목록(현지조사시 생태계교란생물 출현위치도) 만들기
- `tools/build_land.py`: 바다를 가를 육지(시군구 경계) 조각 만들기
- `tools/build_ecnat.py`, `tools/build_vegclim.py`, `tools/build_flora.py`: 생태·자연도·식생기후대·식물상 지역 자료
- `인증키 저장.bat`, `tools/save-key.ps1`: 브이월드 인증키 저장
- 필요할 때만 불러오는 도구: shpjs 4.0.4, JSZip 3.10.1, turf 7.1.0(주변 범위), jsPDF 2.5.1. 늘 쓰는 도구: Leaflet 1.9.4, proj4 2.9.0, d3 7.9.0
